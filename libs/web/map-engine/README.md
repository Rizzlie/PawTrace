# map-engine

Angular map host (`MapEngine`, selector `pt-map`) and its component-scoped `LeafletMap` service. Consumed as `@pawtrace/map-engine`; Leaflet types do not cross the public interface. `MapEngine` provides and injects the service, initializes it after rendering, and Angular calls `ngOnDestroy` when that host is removed. Separate hosts receive separate service instances.

The host passes its readonly configuration and viewport signals into the service once. The service derives source configuration directly from these inputs rather than copying values through effects. Readonly `basemap`, `loading`, `tileMessage`, `locating`, `locationMessage`, `satelliteAvailable` and `showMapboxLogo` signals are consumed directly by the template. `computed` resolves the active source and logo; `linkedSignal` keeps selection valid as satellite access changes and resets source errors when the source changes. `afterRenderEffect` synchronizes source/retry changes and viewport input with Leaflet. Imperative Leaflet callbacks update observed state; these state changes do not recreate the layer. Geolocation and its status also belong to the service.

Inputs are plain `MapConfig` (public browser token and optional source/attribution pairs) and optional `MapViewport` (latitude, longitude, zoom). `viewportChanged` emits completed navigation, including a user-requested device location. Programmatic restoration and container resize do not emit edits. Restoration is asynchronous: the latest requested view is coalesced, survives a queued/in-flight zoom animation, and applies after that animation ends. Suppression lasts until the requested view is applied. Destruction cancels pending restoration. The host does not inject an application store or persist a case. F07 adds plain `places` and `pointDraft` inputs, `placeSelected` and session-correlated `pointPlaced` outputs. Stable IDs reconcile committed markers; draft markers are separately draggable and cleaned up on session end. Navigation emits no geometry edit. Longitudes are wrapped to geographic coordinates. Clicking points within 28 screen pixels offers their names without zooming. Names use text/attribute assignment rather than HTML interpolation. Area geometry follows in F09.

The service owns the map, active basemap, temporary location/accuracy layers, listeners, satellite load timeout and ResizeObserver. Removal completes Leaflet's own cleanup before detaching remaining listeners. Both layers share the same map instance and supported display zoom range 3–22. Component destruction cancels pending work and disconnects the observer/listeners; if a CSS zoom is in flight, final map removal waits for its completion so Leaflet's own timer cannot touch a deleted map pane. Late geolocation callbacks are ignored.

`parseMapConfig` validates the public runtime DTO. Optional `osm` and `satellite` settings each contain `urlTemplate` and `attribution`; absent settings retain defaults. Templates contain `{z}/{x}/{y}` and may use `{accessToken}`. Basic sources use 256-pixel XYZ tiles; satellite sources use 512-pixel tiles and offset -1. The service sanitizes attribution, updates active source settings without changing the viewport, and preserves default OSM access when the API configuration is invalid.

The application supplies Leaflet CSS globally. Mapbox mode also expects the official logo at `assets/mapbox-logo.svg`. Configuration transport belongs to the app/API, not this library.

Tile responses use the browser's ordinary HTTP cache and provider TTL/validators. Leaflet's offscreen `keepBuffer` is separate from that cache. The computed active-source equality preserves the current layer through equivalent configuration, inactive-source edits and status changes, avoiding unnecessary tile requests. Explicit retry replaces the layer without cache-busting URLs. There is no persistent application tile store, prefetch or offline mode.

Run `npm exec nx run map-engine:test`, `npm exec nx run map-engine:typecheck`, or `npm exec nx run map-engine:lint`. The browser acceptance suite is `npm exec nx run web-e2e:e2e`.

The vertical `Działania na mapie` toolbar sits at the top right, leaving the address-search side available for future filters. The basemap toolbar is at the bottom right beside Leaflet zoom controls. Location accuracy is exposed through a Material tooltip on `Moja lokalizacja` (hover, keyboard focus or touch long press), rather than a persistent success message. Progress and failures remain visible in map messages; the position and accuracy circle are temporary rendering layers.

The technical `initialLocation` input defaults to `off`; `show` requests a position without navigation, and `center` may also center the initial view. The workspace waits for case restoration, then chooses `show` for a restored document or `center` for an empty workspace. Only one automatic attempt is made per map host. Any subsequent navigation or viewport input invalidates automatic centering, so a late result can draw the position without overriding a newer view. Explicit location-button requests can center again. This selection policy belongs to the workspace; map-engine has no case-store dependency.

The right map-actions toolbar groups device location and point creation. `pointCreationEnabled` is supplied by the application; `addPointRequested` emits the user intent without injecting case state or deciding editor transitions. Both actions share Angular Aria keyboard navigation and remain available when the place list is collapsed.

The application supplies `number` on place/draft projections. Marker badges render these labels without deriving case ordering. Reconciliation updates the icon when the number or selection changes; location/name updates retain marker identity. The list consumes the same numbered scene as the map.

Display zoom reaches 22 while both tile layers use `maxNativeZoom: 19`, retaining the existing 512px satellite offset of -1. Extra display zoom scales existing tiles rather than increasing requested provider zooms. This supports closer geographic placement and separation without adding imagery detail. See [Leaflet maxNativeZoom](https://leafletjs.com/reference.html#gridlayer-maxnativezoom).
